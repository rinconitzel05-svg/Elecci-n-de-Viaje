# Elecci-n-de-Viaje
# ✈️ Agencia de Viajes – Sistema de Reservaciones

## 📌 Descripción

Este proyecto consiste en el desarrollo de un sistema web de reservaciones para una agencia de viajes. Su objetivo es facilitar la elección y organización de un viaje mediante un proceso sencillo y guiado.

El usuario puede ingresar su nombre, seleccionar el número de personas y noches de hospedaje, elegir un destino turístico, una playa y un hotel. Posteriormente, el sistema calcula automáticamente el costo de la reservación.

El sistema contempla los destinos de **Cancún y Acapulco**, con diferentes opciones de playas y hoteles. Además, cuando el subtotal de la reservación es igual o mayor a **$20,000**, se aplica automáticamente un **10 % de descuento**.

La página fue desarrollada utilizando:

- **HTML** para la estructura del sitio.
- **CSS** para el diseño y presentación visual.
- **JavaScript** para la interacción y los cálculos de la reservación.
- **GitHub Pages** para la publicación del sitio web.

## 🎯 Objetivo

Facilitar la toma de decisiones del viajero y hacer más sencillo, rápido y organizado el proceso de selección de destino y hospedaje.

## 🌴 Funcionalidades

- Registro del nombre del cliente.
- Selección del número de personas.
- Selección del número de noches.
- Selección de destino.
- Selección de playa.
- Selección de hotel.
- Cálculo automático del subtotal.
- Aplicación automática del 10 % de descuento.
- Cálculo del total a pagar.
- Generación de un resumen de la reservación.

## 👥 Usuarios

El sistema está dirigido principalmente a:

- Viajeros o clientes que desean reservar sus vacaciones.
- Personal de una agencia de viajes.
- Administradores del sistema.
